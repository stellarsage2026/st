Disciplines

线上可以参与的方向

三个方向，都支持纯远程协作。没有基础要求，第一次参与也会有人带着走一遍。

01 / VISUAL

视觉设计

海报、封面、排版与修图。远程提交源文件，在线协作走完整流程。

02 / VIDEO

视频剪辑

素材远程传输，剪辑、调色、包装在线上完成，按节点交付。

03 / WEB

网页与工具

写前端、搭页面、做小工具。代码托管在 GitHub，线上同步推进。

Workflow

线上协作的方式

全部流程在线完成，从群组沟通到任务交付，每个环节都有对应工具。

01 / PROJECT

在线项目推进

学社有正在进行的项目，线上成员按自己的节奏认领任务。

02 / IDEA

想法与反馈

群内随时提想法，遇到问题互相给反馈，不做无用的会议。

03 / ASYNC

异步沟通

不强制固定在线时间，按自己的作息参与，消息留言即可。

04 / GROW

从协助到独立

从协助别人的任务开始，逐渐承担独立的部分，全程有人带。
